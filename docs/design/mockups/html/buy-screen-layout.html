Buy screen layout mockups

Static visuals for docs/design/sale-screen-layout.md. Nothing here is wired up. Every frame paints the app's own tokens explicitly, in both palettes, so it looks the same on any device and so a colour that only works in one theme shows up here as a bug. Items and prices are the studio's real ones at the in-studio rate, before the 10.35% tax the receipt adds. No photos, by decision: the type and the layout carry it.

1. Buy, shelf mode, full cart. Light palette. Receipt left and it never moves; one non-wrapping category row with Favorites pinned first; three shelf columns at 190px minimum; a count badge on anything already rung up; and the sticky action bar carrying one primary control with the item count and the server's total. Liquid IV is the selected receipt line, so it is the only one showing quantity controls.

Dry run: taps are rehearsed, nothing reaches Mindbody.
